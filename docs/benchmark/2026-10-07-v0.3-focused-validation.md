## Known validation boundary

The control model now covers delegated Agent/CodingAgent and automatic continuation semantics, but the active Runners advertise no CodingAgent provider.

Therefore this candidate **does not claim an end-to-end PASS** for:

- provider-backed independent CodingAgent workers;
- provider-backed multi-Agent parallel execution;
- production Host auto-resume after AgentWait/Wake.

Those paths remain capability-gated and are scheduled for live validation when the required provider and wake-capable Host path are actually configured.

This is not a blocker for the v0.3 control-plane design because the required downgrade behavior is explicit and testable: preserve the objective/state and fall back to controller / Workflow Session / Job execution without fabricating delegation.
